Texture Cache Addon - Supported Commands
========================================

The following commands are implemented and will work when called from the Kodi addon.

ADDON COMMAND SEQUENCE FORMAT
-----------------------------

In addon settings, enter commands separated by commas:
  c, R, p  — cache, remove orphans, prune (dry-run)
  c movies, R  — cache movies only, then remove orphans
  missing movies "My Movies"  — use quotes for labels with spaces

REQUIREMENTS
------------

- Web server: Enable in Kodi (Settings → Services) for c, C, readfile
- Remote control: Enable "Allow programs on this system to control Kodi"
- imdb: Add omdb.apikey=yourkey to texturecache.cfg
- lastrunfile: Set in config for lc, lnc, lC to work
- network.mac: Set for wake command

COMMAND OUTPUT DISPLAY
----------------------

Output is streamed to a file (no RAM buffer). Foreground runs open a results
window when the sequence finishes. Background and scheduled runs skip that
window — use Last results or Background run status instead. Output is
organized with headers per command.

BACKGROUND RUNS
---------------

Enable Run in background from the main menu or Commands settings. Open the
addon again and choose Background run status to view progress or Stop.
A second start never runs in parallel: you can stop the current run first.

COMMANDS THAT MAY BE LIMITED IN ADDON CONTEXT
---------------------------------------------

j, J, jd, etc.  — Output shown in results modal
monitor         — Blocks until events; progress dialog shows elapsed time
set (stdin)     — Batch mode reads from stdin; addon doesn't provide stdin
update, fupdate — Disabled in addon mode (would kill Kodi)
